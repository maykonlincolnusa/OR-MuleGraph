# OR MuleGraph

Detector explicável de possíveis contas-laranja a partir do comportamento transacional e da posição de cada conta na rede.

## MVP

- Calcular entrada/saída, velocidade, contrapartes e retenção de saldo.
- Identificar pass-through, bursts e redes coordenadas.
- Gerar score com fatores e transações de evidência.
- Comparar contas apenas com grupos comportamentais adequados.

## Próximo passo

O pacote já pontua pass-through rápido, múltiplos remetentes e baixa retenção, explicando os fatores. Próximo: adicionar features de grafo e medir precisão, recall e falsos positivos.
